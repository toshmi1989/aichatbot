# Локальный чатбот (прототип)

Этот репозиторий содержит простой локальный чатбот для тестов, который ищет ответы
по текстовой базе знаний без внешних сервисов.

## Быстрый старт

```bash
python3 chatbot_local.py --source regulation_uz.txt
```

Введите вопрос, чатбот вернёт наиболее релевантные фрагменты.

## Настройки

- `--source` — путь к текстовому файлу базы знаний (по умолчанию `regulation_uz.txt`).
- `--top` — количество возвращаемых фрагментов (по умолчанию 3).
- `--wrap` — ширина переноса строк в выводе (по умолчанию 120).

## Как добавить новые материалы

1. Конвертируйте PDF в текст (UTF-8).
2. Добавьте текстовый файл рядом с репозиторием.
3. Запустите:

```bash
python3 chatbot_local.py --source путь/к/вашему_файлу.txt
```

> Примечание: это черновой прототип без генеративной модели. Он ищет совпадения
> по ключевым словам и возвращает исходные фрагменты.
